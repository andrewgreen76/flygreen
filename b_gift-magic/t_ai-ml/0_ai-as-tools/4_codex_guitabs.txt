Great question — it’s a combination of backend tools plus your chat client UI:

Preview output is generated by the browser tool runner (Playwright in the browser container) when I call run_playwright_script; it renders index.html from the local server and returns an image artifact path that the client displays.

Diffs output is generated by Git commands I run in this repo (for example git diff, git diff --staged).

Logs output is also generated by CLI commands in this repo/environment (for example git log --oneline, server/process logs, etc.).

The tab/pane layout itself (preview tab, diffs tab, logs tab in one row) is controlled by the host application UI, not by me directly.
